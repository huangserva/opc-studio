配置 OAuth 2.0 应用

在 X 开发者控制台 ↗ 的应用中启用用户授权，选择读写权限。填写 OAuth 2.0 Client ID；Web App／自动化应用还需 Client Secret。

凭据仅保存在本机，不会显示在发布记录中。保存应用配置会清除原账号授权。

发布内容

最多 4 张图片，或 1 个动图／视频；串帖附件用于第一条。图片最多 20 MB，超出 X 的 5 MB 时会生成压缩副本；视频最多 1 GB。

任务记录

提交后持续显示进度。异常或部分发布不会自动重发；刷新页面后记录仍保留。

读取评论与提及

按 X API 规则计费，每次最多读取 20 条，不自动翻页。读取自己的提及可能适用自有应用优惠；搜索评论通常按 $0.005／条计费，最终以控制台为准。

确认目标账号与内容

点击确认后会调用 X 官方 API 并消耗额度。公开发布的内容将立即对外可见。
