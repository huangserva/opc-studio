# X 官方接口接入

入口：`http://127.0.0.1:8766/x-official.html`。作品的「平台准备 → X」也有入口，可载入指定保存版本的文字。

## 首次连接

1. 在 X Developer Console 打开自己的应用，启用 OAuth 2.0 用户授权和读写权限。
2. 回调地址准确填写 `http://127.0.0.1:8766/api/x-official/callback`。
3. 在工作台页面配置 **OAuth 2.0 Client ID**；Web App／自动化应用还需 **Client Secret**。原生／公开客户端勾选相应选项。
4. 点击「连接／重新授权 X 账号」，在 X 页面完成用户授权，回到工作台核对账号。

应用的 API Key、App-only Bearer Token 不能替代此处的用户授权。请求权限为 `tweet.read tweet.write users.read media.write offline.access`。过期访问令牌由后台刷新。

凭据保存在 `~/Library/Application Support/ArticleStudio/x-official.json`，权限为 `0600`；状态接口不返回 Secret 或令牌。任务与临时附件独立保存在 `workspace/x-official/`。不修改原作品或 Buffer 配置。

## 当前支持范围

- 普通帖子、逐条串帖、回复：发布前核对账号、正文、目标 ID 与附件；确认后才上传至 X 并提交。
- 图片：本机接受最多 20 MB，超过 5 MB 的静态图片生成 JPEG 压缩副本；最多 4 张。GIF 最多 15 MB。
- 视频：本机入口最多 1 GB；分片上传后轮询 X 处理状态。账户视频时长／格式资格仍由 X 校验。
- 文章：当前入口支持纯文本段落及一张封面，先创建草稿，再单独确认发布。原作品的富文本、正文图片顺序不会导入此入口；完整图文文章继续使用现有文章流程。
- 评论：自己的提及、指定原帖最近 7 天或全历史评论，每次最多 20 条，手动翻页。没有后台自动读取或自动回复。

回复规则、文章资格和费用以 X 实际权限及控制台为准。接口实现不代表某个账号已获得全部资格。媒体／文章尚未使用真实账号执行端到端验证。

## 任务状态

`queued/running/published/draft/partial/unknown/failed`，分别对应排队、执行、已发布、草稿、部分发布、结果待核实及失败。已发布结果保留 X 链接。网络断开、服务端 5xx 或服务重启时不自动重发；部分串帖保留已经成功的帖子。

同一次确认重复点击只返回原任务。相同账号与相同正文／媒体内容已有未明确失败的记录时拒绝再次提交。任务列表每 2 秒更新活动任务，页面隐藏时暂停。

## 主功能入口

作品「平台准备 → X → 发布渠道」可选择官方接口或 Buffer；长文章默认保留本机 Chrome 图文排版流程。官方发布使用已保存版本，自动载入可用素材，核对后才提交。返回的每条帖子链接会关联来源版本，并进入发布反馈可选发布项。

「发布反馈」内读取 X 提及／评论，选择已登记的 X 发布项即可带入原帖 ID，也可粘贴原帖链接。仅点击读取时调用 X，每次最多 20 条，不自动翻页。独立页面保留为维护入口，主流程无需跳转。

## 发布反馈工作区

主入口为「发布反馈」。顶部统一选择账号与今天／昨天／近 7 天／自定义时间；日期分组始终遵循同一筛选范围。左侧每页 10 个帖子，右侧显示原帖、被回复内容、作者与时间，评论每页 20 条；桌面两个区域分别滚动。提及和数据复盘分别切换查看，旧统计导入和版本关联保留。

进入页面、切换帖子、筛选与查看缓存不会请求 X。点击「同步」或「读取更多（计费）」才读远程；补全缺失上下文至多额外查询 20 个原帖／父评论，页面显示计费提示。账号设置集中到顶部弹窗。只有当前 OAuth 授权账号可以同步，其他账号仅查看已有本机登记。数字表示已加载记录，不代表账号全部帖子／评论。未知发布时间明确显示登记时间，不冒充发布时间。「到 X 回复」打开 X 页面，由用户发送。

隔离验收统一运行：`../article-importer/.venv/bin/python tests/e2e/run_x_checks.py`。该脚本使用假 X 接口和临时工作区，分别验证独立入口、主功能集成和新版反馈页面，不读取真实凭据。部署遵循协调者统一装载安排。

原帖与我的回复分开查看；原帖同步使用 exclude=replies,retweets，使每页20个名额不被回复占用。只显示已读取数量，存在后续页时需手动计费读取。原帖与回复的远程分页状态独立保存。图片/头像经 /api/x-official/image 同源展示，只接受 HTTPS pbs.twimg.com 的媒体、头像及banner路径，不携带OAuth凭据、不跟随重定向、最多10MB，响应仅限JPEG/PNG/WebP/GIF。
