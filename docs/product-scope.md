# 产品范围与讨论基线

## 产品定义

内容工作台是面向个人的本地优先知识与内容工作台，采用 remio 式工作方式：接入多源资料，组织与关联内容，查证和问答，形成有依据的创作，把结果持续回收到知识库。

这是产品定义与发展方向，不是完整 remio 功能对等声明。仓库来自个人本地实现，正在去除个人配置耦合、整理依赖与可复现检查。某个模块存在，不等于其所有外部连接器或目标链路已经验证可用。

## 主链路与六页导航

**今日 → 素材库 → 拿去写 → 发布复盘**。

今日聚合已有雷达内容，打开全文后可保存到素材库。素材库管理收藏与资料检索；「拿去写」建立底稿并打开创作台，后台初稿保留事实缺口。创作台保留原作品与版本编辑能力。发布复盘聚合已发布记录、素材来源、指标快照与复盘备注。

主导航固定为：今日、素材库、创作台、发布复盘、商单、设置。商单独立管理履约与收款。设置集中展示来源、定时任务、模型、运行日志、后台服务五块：任务控制与模型切换复用既有写接口，不增加服务启停操作；状态只读本地快照，缺少可靠依据时显示未知，实时状态通过链接进入原页查看。

## 工具与旧版入口

「工具」包含图片生成、视频生成。「旧版」包含线索中心、情报采集、GitHub 来源、定时任务、发布反馈、X 官方接口、知识库、创意回收、提示词卡。所有旧路径保持可访问，保留至 **2026-11-29**，届时另开单决定是否撤除。

事项与日程从导航移除，`/events.html` 可直接打开，事件数据与接口继续保留。线索中心的关联事项、建立待确认事项、从事项导入，以及助手的事件建议跳转，通过开关关闭。线索数据本期不删、不迁移，后续按实际使用指标复盘。

资料、线索、事件、事项与日程仍是不同业务对象，不因入口变化而合并或覆盖原始资料。后台任务与人的待办保持区分。

## 业务对象边界

以下是讨论基线，具体字段、状态与关系以数据模型和接口为准。

| 对象 | 核心含义 |
| --- | --- |
| 资料 | 带出处与内容的源材料，可被查找、引用与组织 |
| 主题资料夹 | 围绕问题或主题组织的材料与引用 |
| 线索 | 商业、技术、热点、项目等值得关注的候选信息与后续变化 |
| 事件 | 有上下文和证据的事件记录，可关联行动事项 |
| 事项 | 具体行动、责任人与进展，可附带时间要求 |
| 日程 | 事件或事项的时间安排；当前页面使用时间排序列表，不能冒称完整日历 |
| 作品与版本 | 创作结果及可追溯版本，不以新结果覆盖历史版本 |
| 平台表现 | 绑定作品与发布记录的观察、指标或快照 |
| 商单 | 独立的商业合作记录，管理履约与收款，可关联资料、作品和事项 |
| 定时任务 | 后台脚本或 Pi 执行计划及运行记录，与人的事项/日程区分 |

商单独立入口是已明确的产品要求。它可以由商业线索产生并关联后续行动，但不能因此收进线索或事项而丢失履约与收款管理。

## 当前代码覆盖与限制

已有代码分别承载作品版本、知识来源与资料夹、线索、事件与行动、商单、定时执行、发布适配和反馈回库；助手通过 Pi stdio 调用业务工具，创作工作流保留阶段与证据记录。

这些能力的实际可用范围由配置、接口合同与测试决定。模型、remio、微信来源、MemOS、媒体生成和平台发布等外部集成需要对应环境，不承诺开箱即用或覆盖所有平台。模型审稿也不能被视为独立事实认证。

基础存储使用 SQLite 与本地文件；本地 HTTP 服务仅监听回环地址。真实资料、历史、凭据与商单属于运行环境，必须与代码仓库分离。

## 使用与验证边界

六页导航与分组已经确定。来源状态、任务状态和采集成功属于不同口径；设置页分别标明数据依据，不把日志更新时间当作运行健康或采集成功。模型密钥仅显示「已配置 / 未配置」，不返回明文；日志仅从白名单文件末尾有界读取并脱敏。

界面验收覆盖真实浏览器操作、具体内容与数据一致性。外部连接器、模型和发布路径仍遵守各自配置与授权；页面存在不代表外部服务已接通。

## 仓库与交付边界

仓库先保持私有，通过 Issue 与 PR 讨论和审查。禁止纳入真实工作空间、会话和运行历史、密钥、Cookie、账户配置、邮件/微信原文、商单与收款记录；测试与复现只使用合成数据。

项目开源许可证尚未决定。vendored OpenPI 保留自己的 MIT 许可与来源记录，不扩大为整个项目的许可决定。仓库整理也不等于部署、生产数据迁移或真实平台发布授权。
